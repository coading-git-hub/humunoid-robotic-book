Digital Twin Workstation Setup

Overview#

This guide covers setting up a digital twin workstation for the course.

Hardware Requirements#

  • GPU: NVIDIA RTX 3080 or higher
  • CPU: Intel i7 or AMD Ryzen 7
  • RAM: 32GB minimum
  • OS: Ubuntu 22.04 LTS

Software Setup#

  1. Install ROS 2 Humble
  2. Install Gazebo
  3. Install Unity
  4. Configure development environment

Verification#

Run test simulations to ensure setup is correct.
